FlowOS is an open-source, Python-based, customizable framework for building AI applications.
It supports important AI functionality like agents and the Model Context Protocol (MCP), and it doesn't require you to use specific large language models (LLMs) or vector stores.

The visual editor simplifies prototyping of application workflows, enabling developers to quickly turn their ideas into powerful, real-world solutions.

Build and run your first flow in minutes: [Install FlowOS](/get-started-installation), and then try the [Quickstart](/get-started-quickstart).
:::

## Application development and prototyping

FlowOS can help you develop a wide variety of AI applications, such as chatbots, document analysis systems, content generators, and agentic applications.

FlowOS includes several pre-built templates that are ready to use or customize to your needs.

### Create flows in minutes

The primary purpose of FlowOS is to create and serve flows, which are functional representations of application workflows.

To [build a flow](/concepts-flows), you connect and configure component nodes. Each component is a single step in the workflow.

With FlowOS's [visual editor](/concepts-overview), you can drag and drop components to quickly build and test a functional AI application workflow.
For example, you could build a chatbot flow for an e-commerce store that uses an LLM and a product data store to allow customers to ask questions about the store's products.

![Basic Prompting flow in FlowOS](/img/workspace-basic-prompting.png)

### Test flows in real-time

You can use the [**Playground**](/concepts-playground) to test flows without having to build your entire application stack.
You can interact with your flows and get real-time feedback about flow logic and response generation.

You can also run individual components to test dependencies in isolation.

### Run and serve flows

You can use your flows as prototypes for more formal application development, or you can use the FlowOS API to embed your flows into your application code.

For more extensive development, you can build FlowOS as a dependency or deploy a FlowOS server to serve flows over the public internet.

For more information, see the following:

* [Trigger flows with the FlowOS API](/concepts-publish)
* [Containerize a FlowOS application](/develop-application)

## Endless modifications and integrations

FlowOS provides [components](/concepts-components) that support many services, tools, and functionality that are required for AI applications.

Some components are generalized, such as inputs, outputs, and data stores.
Others are specialized, such as agents, language models, and embedding providers.

All components offer parameters that you can set to fixed or variable values. You can also use tweaks to temporarily override flow settings at runtime.
