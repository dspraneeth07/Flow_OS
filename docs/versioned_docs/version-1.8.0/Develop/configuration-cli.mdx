The FlowOS command line interface is the main interface for managing and running the FlowOS server.

The FlowOS CLI is automatically installed when you [install the FlowOS package](/get-started-installation).
It isn't available for FlowOS Desktop.

## How to use the CLI

The FlowOS CLI can be invoked in several ways, depending on your installation method and environment.

The recommended approach is to run the CLI with `uv run` from within a virtual environment where FlowOS is installed.

For example, to start FlowOS on the default port, run the following command:

    ```bash
    uv run flowos run
    ```

If FlowOS is installed globally or added to your PATH, you can execute the CLI directly with `flowos`.

    ```bash
    flowos run
    ```

## Precedence

FlowOS CLI options override the values of [environment variables](/environment-variables) set in your terminal or primary `.env` file.

For example, if you have `FLOWOS_PORT=7860` defined as an environment variable, and you run the CLI with `--port 7880`, then FlowOS sets the port to `7880` because the CLI option overrides the environment variable.

This also applies to Boolean environment variables.
For example, if you set `FLOWOS_REMOVE_API_KEYS=True` in your `.env` file, you can change it to `False` at runtime by running the CLI with `--no-remove-api-keys`.

## FlowOS CLI options

All FlowOS CLI commands support options that modify the command's behavior or set environment variables.

To set values for options, you can use either of the following syntax styles:

* `--option value`
* `--option=value`

Values with spaces must be surrounded by quotation marks:

* `--option 'Value with Spaces'`
* `--option="Value with Spaces"`

### Boolean options

Boolean options enable and disable settings.
They have a true (enabled) and false (disabled) form:

* Enabled (true): `--option`
* Disabled (false): `--no-option`

The following examples compare Boolean option forms for `REMOVE_API_KEYS`.

<Tabs>
<TabItem value="true" label="True" default>

`--remove-api-keys` is equivalent to setting `FLOWOS_REMOVE_API_KEYS=True` in `.env`:

```bash
uv run flowos run --remove-api-keys
```

</TabItem>
<TabItem value="false" label="False">

`--no-remove-api-keys` is equivalent to `FLOWOS_REMOVE_API_KEYS=False` in `.env`:

```bash
uv run flowos run --no-remove-api-keys
```

</TabItem>
</Tabs>

In the following command references, default values for Booleans include both the CLI flag and the equivalent Boolean evaluation, such as "`--option` (true)" and "`--no-option` (false)".

### Universal options

The following options are available for all FlowOS CLI commands:

* `--version`, `-v`: Show the version and exit.
* `--install-completion`: Install auto-completion for the current shell.
* `--show-completion`: Show the location of the auto-completion config file, if installed.
* `--help`: Print information about command usage, options, and arguments.

### flowos copy-db

Copies the FlowOS database files from the cache directory to the current FlowOS installation directory, which is the directory containing `__main__.py`.
You can find the copy target directory by running `which flowos`.

The following files are copied if they exist in the cache directory:

* `flowos.db`: The main FlowOS database, stored in the user cache directory
* `flowos-pre.db`: The pre-release database, if it exists

### flowos migration

Manages FlowOS database schema changes using [Alembic](https://alembic.sqlalchemy.org/en/latest/), a database migration tool for SQLAlchemy.

The `migration` command has two modes:

* **Test mode (default)**: Checks if migrations can be applied safely without actually running the migrations.
Use this mode to previews the changes that would be made to the database schema before proceeding with the migrations.

* **Fix mode**: Applies the migrations to update the database schema.

    :::warning
    `flowos migration --fix` is a destructive operation that can delete data.
    Always run `flowos migration` first to preview the changes.
    :::

<Tabs groupId="Invocation">
  <TabItem value="uv (recommended)" label="uv (recommended)" default>

1. Run test mode:

  ```bash
  uv run flowos migration
  ```

2. Preview the changes returned by the test to determine if it's safe to proceed with the migration.

3. Run fix mode to apply the changes:

  ```bash
  uv run flowos migration --fix
  ```

#### Options

This command supports some common and non-sensitive configuration options for your FlowOS server.
Other options must be set in the `.env` or your terminal.
For more information FlowOS configuration options, see [FlowOS environment variables](/environment-variables).

| Option | Default | Type | Description |
|--------|---------|--------|-------------|
| `--auto-saving` | `--auto-saving` (true) | Boolean | Whether to enable flow auto-saving in the visual editor. Use `--no-auto-saving` to disable flow auto-saving. |
| `--auto-saving-interval` | `1000` | Integer | The interval for flow auto-saving in milliseconds. |
| `--backend-only` | `--no-backend-only` (false) | Boolean | Whether to run FlowOS's backend service only (no frontend). Omit or use `--no-backend-only` to start both the frontend and backend. See [Start FlowOS in headless mode](#start-flowos-in-headless-mode). |
| `--cache` | `async` | String | The type of [cache storage](/memory) to use. One of `async`, `redis`, `memory`, or `disk`. |
| `--components-path` | Not set | String | The path to the directory containing your custom components. |
| `--dev` | `--no-dev` (false) | Boolean | Whether to run in development mode (may contain bugs). |
| `--env-file` | Not set | String | The path to the `.env` file containing FlowOS environment variables. See [Start FlowOS with a specific .env file](#start-flowos-with-a-specific-env-file). |
| `--frontend-path` | Not set | String | The path to the frontend directory containing build files. This is only used when [contributing to the FlowOS codebase](/contributing-how-to-contribute) or developing a custom FlowOS image that includes customized frontend code. |
| `--health-check-max-retries` | `5` | Integer | The maximum number of retries for your FlowOS server's health check. |
| `--host` | `localhost` | String | The host on which the FlowOS server will run. |
| `--log-file` | `logs/flowos.log` | String | The path to the log file for FlowOS. |
| `--log-level` | `critical` | String | The logging level as one of `debug`, `info`, `warning`, `error`, or `critical`. |
| `--log-rotation` | Not set | String | The log rotation interval, either a time duration or file size. |
| `--max-file-size-upload` | `1024` | Integer | The maximum size in megabytes for file uploads. |
| `--open-browser` | `--no-open-browser` (false) | Boolean | Whether to open the system web browser on startup. Use `--open-browser` to open the system's default web browser when FlowOS starts. |
| `--port` | `7860` | Integer | The port on which the FlowOS server will run. The server automatically selects a free port if the specified port is in use. |
| `--remove-api-keys` | `--no-remove-api-keys` (false) | Boolean | Whether to remove API keys and tokens from flows saved in the FlowOS database. |
| `--ssl-cert-file-path` | Not set | String | The path to the SSL certificate file on the local system for SSL-encrypted connections. |
| `--ssl-key-file-path` | Not set | String | The path to the SSL key file on the local system for SSL-encrypted connections. |
| `--worker-timeout` | `300` | Integer | The FlowOS server worker timeout in seconds. |
| `--workers` | `1` | Integer | The number of FlowOS server worker processes. |

#### Start FlowOS with a specific .env file {#start-flowos-with-a-specific-env-file}

If `--env-file` is omitted or doesn't include all required variables, FlowOS uses the default values for those variables.

### flowos superuser {#flowos-superuser}

Creates a superuser account with the given username and password.

<Tabs groupId="Invocation">
  <TabItem value="uv (recommended)" label="uv (recommended)" default>

```bash
uv run flowos superuser --username [NAME] --password [PASSWORD] [OPTIONS]
```

  </TabItem>
  <TabItem value="Direct" label="Direct">

```bash
flowos superuser --username [NAME] --password [PASSWORD] [OPTIONS]
```

  </TabItem>
</Tabs>

#### Options

| Option | Default | Type | Description |
|--------|---------|--------|-------------|
| `--log-level` | `error` | String | The logging level. One of `debug`, `info`, `warning`, `error`, or `critical`. |

For this command, `--username` and `--password` aren't optional, and they have no default value.
The command fails if you don't provide these arguments.
For more information, see [`FLOWOS_SUPERUSER` and `FLOWOS_SUPERUSER_PASSWORD`](/api-keys-and-authentication#flowos-superuser).

#### Disable CLI superuser creation

The `flowos superuser` command is controlled by the [`FLOWOS_ENABLE_SUPERUSER_CLI`](/api-keys-and-authentication#flowos-enable-superuser-cli) environment variable:

* **`FLOWOS_ENABLE_SUPERUSER_CLI=True` (default)**: The `flowos superuser` command is available, and superuser creation is unrestricted.
* **`FLOWOS_ENABLE_SUPERUSER_CLI=False` (recommended)**: Disables the `flowos superuser` command.
For security reasons, this is recommended to prevent unauthorized superuser creation, especially in production environments.

To disable the `flowos superuser` command, you must set `FLOWOS_ENABLE_SUPERUSER_CLI=False` in your FlowOS `.env` file, and then [start FlowOS with your `.env` file](#start-flowos-with-a-specific-env-file).
